# Egg Agent Survivor

**你是最后一枚未破壳的特工。武器会自动开火，你只需要走位、构筑，然后活下去。**

Egg Agent Survivor 是一款浏览器原生的霓虹风 Roguelike 生存射击游戏。玩家要在不断加速的蛋巢围攻中收集经验、从三张升级卡中搭建武器组合，并挑战会变招、可处决的“蛋皇”Boss。项目使用原生 HTML、CSS、JavaScript 与 Canvas 2D，不需要打包，也没有运行时依赖。

> 本项目是独立作品，与《弹壳特攻队》（Survivor.io）及其开发商没有隶属或授权关系。下方对比仅用于说明玩法定位。

## 游戏循环

1. 移动躲避敌人，所有武器全自动索敌或按移动方向攻击。
2. 拾取经验晶体升级，从新武器、武器强化、被动属性中三选一。
3. 让不同元素武器命中同一目标触发反应；两把对应的 5 级武器还能融合成高阶武器。
4. 应对每 30 秒升级一次的波次，以及包围圈、冲锋列、精英小队等随机事件。
5. 每 5 波迎战一次蛋皇；Boss 低血量时抓准收缩光环完成处决。
6. 延续击杀累积连击。30 连击会进入 8 秒 Fever，获得伤害与射速加成。
7. 蛋壳破碎后以生存时间、等级、击杀、最高连击和总分结算，再构筑一局。

## 核心特色

- **即开即玩**：零构建、零前端框架，现代浏览器访问静态目录即可运行。
- **十六武器构筑**：6 把基础武器覆盖追踪、环绕、弹射、范围与控制，另有 10 把融合武器。
- **五元素反应**：火、冰、雷、毒、光两两组合可触发蒸发、超载、超导、净化等 10 种反应。
- **动态战场**：无限波次、6 类常规敌人、精英变体、随机波次事件和多阶段 Boss。
- **三选一策略**：18 种可叠加被动、稀有度与幸运权重、重随和本局卡池消除。
- **连击与 Fever**：连得越高续连窗口越短，达到 30 连击后进入爆发阶段。
- **Boss 处决 QTE**：在金色判定带内按键或点击可立即处决；失手会令 Boss 暴怒。
- **桌面与移动端适配**：键盘、虚拟摇杆、安全区布局、横竖屏和自动暂停均已支持。
- **自适应性能**：高、均衡、性能三档会按实时帧率切换，并对远处敌人和粒子降级。
- **程序化音效与打击反馈**：无需外部音频文件，包含震屏、定格、闪光、飘字和空间提示。

## 操作说明

所有武器自动攻击，玩家无需瞄准或点击射击。

| 场景 | 键盘操作 | 触屏操作 |
| --- | --- | --- |
| 移动 | `WASD` 或方向键 | 在屏幕左半区按住并拖动虚拟摇杆 |
| 相位冲刺 | `Shift` 或空格 | 当前版本建议使用带键盘设备 |
| Boss 处决 | `E`、`F` 或 `Enter` | 在处决光环进入金色判定带时点击 |
| 暂停 / 继续 | `Esc` 或 `P` | 点击右上角暂停按钮 |
| 静音 / 开声 | `M` | 点击右上角音符按钮 |
| 开始 / 重试 | `Enter` | 点击对应按钮 |
| 选择升级 | `1` / `2` / `3` | 点击升级卡 |
| 重随升级 | `R` | 点击“重随三选一” |
| 消除升级卡 | 右键卡片（每局 1 次） | 当前版本仅支持鼠标右键 |

切换到其他标签页时游戏会自动暂停。浏览器首次交互后才会启用音效，这是浏览器的自动播放限制。

## 武器表

每局默认携带“魔法弹”，最多同时占用 6 个武器槽。伤害、数量、范围或冷却会随等级成长。

### 基础武器

| 武器 | 元素 | 等级上限 | 定位 | 攻击机制 |
| --- | --- | ---: | --- | --- |
| 飞刀环绕 | 毒 | 8 | 贴身防守 | 多把飞刀绕身持续切割，逐级增加数量、轨道与转速 |
| 魔法弹 | 光 | 8 | 稳定单体 | 自动锁定最近目标并追踪，可获得多发与穿透 |
| 闪电链 | 雷 | 8 | 群体清场 | 优先攻击强敌，并在附近敌人之间连续弹射 |
| 火焰喷射 | 火 | 8 | 扇形持续伤害 | 朝移动方向喷火；站定时索敌，并附加灼烧 |
| 霜爆冲击 | 冰 | 6 | 解围控制 | 周身环形爆发，击退并减速近处敌人 |
| 回旋蛋镖 | 物理 | 6 | 直线穿透 | 飞出后返回，往返路径都能穿透敌群；不参与元素融合 |

### 元素反应与融合武器

火、冰、雷、毒、光武器会给敌人留下短暂印记。用另一种元素命中可触发对应反应；同一元素对的两把源武器都达到 5 级后，下一次升级三选一会保底出现传说融合卡。

选择融合会吞掉两把源武器、生成对应融合武器并净腾出 1 个槽位。源武器超过 5 级的部分会按比例折算为融合等级；每局最多持有 2 把融合武器。

| 融合武器 | 元素组合 | 等级上限 | 机制 |
| --- | --- | ---: | --- |
| 蒸汽奇点 | 火 + 冰 | 6 | 游走的高压蒸汽涡旋，牵引敌人并持续蒸灼 |
| 等离子风暴 | 火 + 雷 | 6 | 在怪群头顶落下连环等离子轰击 |
| 硫磺瘟疫 | 火 + 毒 | 6 | 在敌人脚下生成同时灼烧与毒蚀的区域 |
| 日冕新星 | 火 + 光 | 6 | 以自身为中心释放大范围圣焰爆发环 |
| 超导力场 | 冰 + 雷 | 6 | 常驻减速力场，并周期性发射电弧 |
| 凛冬荆棘 | 冰 + 毒 | 6 | 淬毒冰棘环绕旋转，缓速并毒蚀近身敌人 |
| 极光棱镜 | 冰 + 光 | 6 | 旋转极光射线，冻结并撕裂整条直线 |
| 腐电蛛网 | 毒 + 雷 | 6 | 毒电弧在敌群中连续跳跃并传播毒层 |
| 天雷裁决 | 光 + 雷 | 6 | 圣光天雷轰击最强目标并眩晕周围敌人 |
| 辉光瘟疫 | 光 + 毒 | 6 | 放出追踪孢子群，净化毒层并回复生命 |

## 升级与生存技巧

- 第一优先是保持移动，不要为了捡一颗经验晶体穿过怪群；磁力场可以降低拾取风险。
- 前期先建立 2–3 种互补武器，再提升主力等级。只有伤害而没有控制时，后期很容易被合围。
- 每局初始有 1 次重随和 1 次消除；之后每选择 5 次升级会返还 1 次重随机会。
- 想走融合路线时，优先把目标元素的两把武器都升到 5 级；融合卡出现后也可暂缓选择，先抬高源武器等级以获得更多等级结转。
- 连击倍率会提高得分，Fever 才会提高战斗力。想续连时应向下一批敌人移动，而不是原地等怪。
- Boss 血量低于约 22% 时会开启一次处决窗口。等待收缩环进入金色区域再按键；抢按、超时都会触发暴怒。
- 更短的实战路线与推荐构筑见 [PLAY.md](./PLAY.md)。

## 快速启动

### 环境要求

- Python 3：启动本地静态服务器。
- 现代浏览器：推荐最新版 Chrome、Edge、Firefox 或 Safari。
- Node.js 18+：仅运行测试、探针和开发辅助命令时需要。

```bash
git clone <repository-url>
cd egg-agent-survivor
npm run dev
```

开发服务器默认监听 `0.0.0.0:3000`，并尝试自动打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止。

按需覆盖地址、端口或禁用自动打开浏览器：

```bash
HOST=127.0.0.1 PORT=4173 npm run dev
OPEN_BROWSER=0 npm run dev
```

也可以直接运行 `./scripts/dev-server.sh`。在无桌面环境或系统没有可用的 URL 打开器时，脚本会保留服务器并打印访问地址。

## 开发命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动游戏并自动尝试打开浏览器 |
| `npm test` | 运行全部 Node 测试 |
| `npm run probe` | 检查必需文件、本地资源引用和 JavaScript 语法 |
| `npm run benchmark` | 启动性能基准页；打开输出中的 `?autorun=1` 或 `?stress=1` 地址 |

基准服务默认使用 `127.0.0.1:4173`，可通过 `HOST`、`PORT` 覆盖。详细参数运行：

```bash
./scripts/run-benchmark.sh --help
```

## 部署

项目没有构建步骤。部署产物就是仓库中的 `index.html`、`css/` 和 `js/`；请同时保留目录结构。测试、脚本和 `.agent_workspace/` 不影响运行，可在生产发布时排除。

### GitHub Pages

1. 将仓库推送到 GitHub。
2. 在 **Settings → Pages** 中选择 **Deploy from a branch**。
3. 选择发布分支与根目录 `/`，保存后访问 Pages 给出的 HTTPS 地址。

资源均使用相对路径，因此部署在仓库子路径下也能工作。

### Netlify / Vercel / 其他静态平台

- 发布目录：项目根目录 `.`。
- Build command：留空。
- Install command：留空。
- Framework preset：`Other` / `Static`。

平台分配域名后直接访问根路径即可，不需要服务端 API 或环境变量。

### Nginx

将项目复制到例如 `/var/www/egg-agent-survivor`，并配置：

```nginx
server {
    listen 80;
    server_name game.example.com;
    root /var/www/egg-agent-survivor;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

生产环境建议启用 HTTPS。页面会从 Google Fonts 获取字体；网络不可达时会自动使用本地后备字体，不影响游戏逻辑。

## 与《弹壳特攻队》的特色对比

| 维度 | Egg Agent Survivor | 《弹壳特攻队》式商业手游体验 |
| --- | --- | --- |
| 获取与运行 | 浏览器链接即玩，无安装、无账号 | 通常需安装客户端并进入账号体系 |
| 操作核心 | 自动攻击 + 走位 + 冲刺 + Boss 处决 QTE | 自动攻击 + 走位，长期系统更丰富 |
| 单局构筑 | 6 把基础武器、10 把元素融合武器、18 种被动、重随与卡池消除 | 武器、技能合成与装备体系规模更大 |
| 节奏特色 | 连击计分与 30 连击 Fever 爆发 | 更强调关卡推进与长期数值成长 |
| Boss 表现 | 多阶段招式、屏外指示、低血量手动处决 | Boss 与关卡种类更多，内容体量更大 |
| 局外成长 | 当前不设付费、体力或永久属性养成 | 通常包含装备、角色、任务等长期成长 |
| 技术定位 | 原生 Canvas 2D、零构建、源码可读 | 商业客户端，完整内容与在线服务 |
| 适合场景 | 快速试玩、教学、二次开发、短局挑战 | 长期游玩、内容收集与持续运营 |

Egg Agent Survivor 的重点不是复刻商业手游的内容体量，而是把“自动战斗 + 走位构筑”的核心循环压缩成可分享、可修改、打开即玩的独立网页游戏。
