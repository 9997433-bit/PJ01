# Egg Agent Survivor 快速上手

从启动到第一只 Boss，只需要记住三件事：**保持移动、武器自动攻击、升级时补齐输出与控制。**

## 1 分钟开玩

```bash
cd egg-agent-survivor
npm run dev
```

脚本会尝试自动打开 <http://127.0.0.1:3000>。看到主菜单后点击“开始任务”或按 `Enter`。

如果浏览器没有自动打开，请手动访问终端显示的地址。无桌面环境可用：

```bash
OPEN_BROWSER=0 npm run dev
```

## 你的目标

- 敌人会持续从视野外接近，武器自动攻击。
- 击败敌人并拾取发光经验晶体；经验条满后会暂停游戏并出现三张升级卡。
- 波次每 30 秒增强，每 5 波出现蛋皇 Boss。
- 尽可能延长生存时间，同时冲击最高连击和得分。

## 最少操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 左半屏按住拖动 |
| 冲刺 | `Shift` / 空格 | 当前版本建议使用键盘 |
| 暂停 | `Esc` / `P` | 右上角暂停按钮 |
| Boss 处决 | `E` / `F` / `Enter` | 在正确时机点击屏幕 |
| 选升级 | `1` / `2` / `3` | 点击卡片 |
| 重随 | `R` | 点击重随按钮 |
| 静音 | `M` | 右上角音符按钮 |

武器不需要瞄准。冲刺可快速穿出包围，但有冷却，不要连续浪费。

## 第一局推荐路线

### 开局：先站稳

初始武器“魔法弹”会自动追踪最近敌人。沿宽弧线绕怪，不要贴着屏幕边缘直跑，否则容易被两侧夹击。

升级优先级建议：

1. **霜爆冲击**：击退和减速是最直接的容错。
2. **飞刀环绕**：清理贴身敌人，保护走位空间。
3. **蛋白强化 / 急速孵化**：提升全局伤害或攻击频率。
4. **推进器 / 强化蛋壳 / 纳米修复**：走位不熟时优先补生存。

### 中段：建立清场能力

获得控制后，选择“闪电链”处理密集怪群，或用“火焰喷射”覆盖移动方向。不要只拿被动而一直维持单武器；2–3 种互补攻击通常比单一路线更稳。

- 怪群密集：闪电链、火焰喷射。
- 经常被贴身：飞刀环绕、霜爆冲击。
- 想安全绕圈：魔法弹、回旋蛋镖。
- 武器已经成形：补冷却、范围、伤害、暴击。

### Fever：主动续连

每次击杀都会刷新连击计时，连击越高，可续连的时间越短。达到 30 连击后进入 8 秒 Fever：

- 武器伤害提升；
- 武器冷却缩短；
- 得分倍率锁定在最高档。

连击条快空时，向敌人更密集的方向移动，不要停在刚清空的区域。

## 升级卡怎么选

- **新武器**：增加一种攻击方式，占用 1 个武器槽，最多 6 槽。
- **武器升级**：强化已经持有的武器；飞刀、魔法弹、闪电链、火焰最高 8 级，霜爆与回旋镖最高 6 级。
- **被动属性**：可重复叠加，但每种有次数上限。
- **融合武器**：两把不同元素的源武器都达到 5 级后出现，会用两把源武器合成一把高阶武器。
- **重随**：每局初始 1 次，每选择 5 次升级再获得 1 次。
- **消除**：用鼠标右键一张卡，可令它本局不再出现；每局 1 次。

简单判断法：**先拿缺少的战斗功能，再强化主力数值。** 被围就补控制或移速，打不动就补伤害或冷却。

## 元素融合速记

基础武器元素：火焰喷射 = 火、霜爆冲击 = 冰、闪电链 = 雷、飞刀环绕 = 毒、魔法弹 = 光。回旋蛋镖是纯物理武器，不参与融合。

不同元素连续命中同一目标会触发元素反应。想得到融合武器，需要把对应的两把源武器都升到 5 级；符合条件后，升级三选一会保底给出传说融合卡。融合会把两把源武器换成一把融合武器，净空出 1 个槽位，每局最多融合 2 次。

适合第一局尝试的路线：

- **魔法弹 + 霜爆冲击 → 极光棱镜**：开局容易成形，兼顾追踪和控制。
- **火焰喷射 + 闪电链 → 等离子风暴**：主动清理密集怪群，爆发高。
- **飞刀环绕 + 霜爆冲击 → 凛冬荆棘**：贴身防守稳定，适合走位练习。

融合不是越早越好。源武器超过 5 级的等级会部分结转，当前生存压力不大时可以先多升几级再融合。

## 蛋皇处决

每 5 波会出现蛋皇。Boss 有多阶段招式，屏外时 HUD 边缘会显示方向和距离。

当 Boss 血量低于约 22% 时，它会停止行动并出现一次收缩光环：

1. 不要立刻按键。
2. 观察外圈向 Boss 收缩。
3. 光环进入金色判定带时按 `E`、`F`、`Enter`，或点击屏幕。
4. 成功会直接处决并获得额外经验；抢按或超时会让 Boss 暴怒，且不会再给第二次机会。

## 看懂 HUD

- 左上：等级与经验。
- 顶部中央：本局生存时间。
- 右上：击杀、FPS、音效和暂停。
- 屏幕侧边：连击数、分数倍率、Fever 进度。
- 左下：蛋壳耐久（生命）。
- 下方：冲刺冷却。
- 屏幕边缘箭头：视野外的 Boss、精英或处决目标。

## 常见问题

**页面打开后没有声音？**
先点击“开始任务”或按一次键。浏览器要求用户交互后才能启用音频；也请确认右上角不是静音状态。

**页面切走后为什么暂停？**
这是防止角色在后台被击败的设计。回到页面后点击继续。

**手机上看不到摇杆？**
在屏幕左半区按下并拖动后，虚拟摇杆才会出现。右半区保留给按钮与处决点击。

**想换端口？**

```bash
HOST=127.0.0.1 PORT=4173 npm run dev
```
