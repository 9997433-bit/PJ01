## A. 音频（P0）

| # | 验收项 | 通过阈值 | 验证方法 |
|---|---|---|---|
| A1 | Web Audio 合成 SFX 种类 | ≥12 种独立音色，且现有 15 个挂点 id（shoot/zap/flame/nova/throw/fuse/spit/bossPhase/bossSpawn/bossDie/kill/gem/pickup/hit/crit）全部有声或显式映射 | 代码审查 `AudioSystem` 音色表；游玩 1 局逐事件听检 |
| A2 | BGM 分层 | 3 层状态（常规/高压/Boss）自动切换；Boss 出场 ≤1s 内完成切层，Boss 死亡后回落 | 打到第 5 波 Boss 出场/击杀，听层切换；代码审查订阅 `wave:boss` 事件 |
| A3 | 拾取音高阶梯 | 连续拾取 0.1s 窗口内音高 +1 semitone，封顶 +12；间隔 >0.6s 重置。连拾 20 颗宝石可听出爬升（SOTA F3 原文标准） | 吃 magnet 道具全屏吸取，录音或听检音高单调上升 |
| A4 | 防爆音 | 主输出接 DynamicsCompressor（或等效限幅）；同 id SFX 并发 ≤4 声道，超出丢弃/偷声道 | 代码审查 + `?stress=500` 满武器压测无破音、无爆红 console |
| A5 | 自动播放策略合规 | 首次用户手势（pointerdown/keydown）后 AudioContext 为 running；此前零 console 警告/报错 | 冷加载页面 → 打开 DevTools console → 点击开始，检查无 `AudioContext was not allowed` 类警告 |
| A6 | 静音开关 | 提供全局静音（UI 按钮或 M 键），状态持久化 localStorage，切换即时生效 | 手动切换后刷新页面验证持久化 |
| A7 | 无音频泄漏 | 一局 10 分钟内活跃 AudioNode 数量有界（振荡器用完即 disconnect），无单调增长 | DevTools Performance/Memory 采样对比开局与 10 分钟时 |

| # | 验收项 | 通过阈值 | 验证方法 |
|---|---|---|---|

| D2 | 帧率采集 | 内建采集器输出 30s 的 P50/P95/P99 帧时长与 >50ms 长帧数（console 或页内面板） | `?stress=500&profile=1` 运行 30s 导出 |

## 验收执行顺序（建议）

1. `node --test tests/*.test.js` 全绿（F1 前半）；
2. `npm run dev` → 完整游玩一局走查 A/B/C 条款（F2 同步覆盖）；
3. `?stress=500&profile=1` 跑 D 条款 → 写 `PERF_REPORT_R2.md`；
4. 设备模拟跑 E 条款 → 截图入库；
5. 汇总勾选本文件全表，未过项写明原因与残留风险。

**判定标准：A~D 全部 P0 条款（A1~A7、B1~B4、C1~C3、D1~D5、D7~D8、D10）+ F 全部通过 = R2 验收通过；P1 条款允许 ≤3 项带偏差通过但须书面记录。**
