# UI 视觉风格指南 — 深色霓虹科幻风 + 圆润 UI

> 配套文档：`SOTA_CHECKLIST.md`（目标 I1：全部 UI 取自本文件定义的 token，禁止游离硬编码）
> 风格定位：**Dark Neon Sci-Fi × Soft Rounded** —— 深空底色上的霓虹光效，配圆角胶囊化的柔和控件。危险与奖励靠"色相 + 形状"双通道编码。

---

## 一、设计原则（Top 5）

1. **暗底亮物（Dark Canvas, Glowing Subjects）**：背景永远压暗（亮度 <15%），所有可交互/可拾取实体自发光。视觉层级 = 发光强度层级：玩家 > 奖励 > 敌人 > 场景。
2. **霓虹只给语义（Neon Means Something）**：高饱和霓虹色仅用于语义传达（危险/奖励/能量/稀有度），装饰性元素一律低饱和。全屏同时出现的霓虹色相 ≤4 种。
3. **圆润无锐角（Everything Rounded）**：所有 UI 容器、按钮、条形控件使用大圆角或胶囊形；锐角仅保留给"危险"语义（警告条纹、Boss 预警）。
4. **单注视区（One Glance Zone）**：战斗信息收拢到"顶部状态条 + 角色周边"两个注视区，屏幕中央 60% 区域无常驻 UI。
5. **动效表达物理（Motion = Physics）**：所有动效基于缓动物理（弹性/惯性），无线性动画；一切过渡 ≤300ms，战斗中的 UI 反馈 ≤120ms。

## 二、色板（Color Tokens）

### 2.1 基底色（Backgrounds & Surfaces）

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-space` | `#0A0E1A` | 全局最底层背景（深空蓝黑） |
| `--bg-arena` | `#111827` | 战斗场地底色 |
| `--surface-1` | `#1A2236` | 面板/卡片底（一级浮起） |
| `--surface-2` | `#242F4B` | 嵌套容器/hover 态（二级浮起） |
| `--surface-glass` | `rgba(26,34,54,0.72)` + `backdrop-blur(12px)` | HUD 半透明玻璃底 |
| `--stroke-dim` | `rgba(122,162,255,0.16)` | 面板描边（1px，常态） |

### 2.2 霓虹主色（Neon Accents — 语义色）

| Token | 色值 | 语义 | 发光（box/drop-shadow） |
|-------|------|------|------------------------|
| `--neon-cyan` | `#00E5FF` | 主品牌色 / 玩家 / 能量 / 主按钮 | `0 0 12px rgba(0,229,255,0.55)` |
| `--neon-magenta` | `#FF2E97` | 强调 / 暴击 / 稀有事件 | `0 0 12px rgba(255,46,151,0.55)` |
| `--neon-lime` | `#B6FF3B` | 经验宝石 / 成长 / 升级 | `0 0 10px rgba(182,255,59,0.5)` |
| `--neon-amber` | `#FFB020` | 金币 / 宝箱 / 传说稀有度 | `0 0 10px rgba(255,176,32,0.5)` |
| `--neon-red` | `#FF3B5C` | 危险 / 敌方预警 / HP 低 | `0 0 14px rgba(255,59,92,0.6)` |
| `--neon-violet` | `#9D6BFF` | 史诗稀有度 / Boss 能量 | `0 0 12px rgba(157,107,255,0.5)` |

**使用规则**：
- 危险（`--neon-red`）必须叠加形状冗余：45° 警告条纹或三角图标（色弱双通道，对应 SOTA 弱点 #12）。
- 经验/奖励用 lime/amber，与危险红在色相环上相距 >120°，永不混用。
- 发光一律用双层：内层实色 1px 描边 + 外层同色 55% 透明扩散，避免"纯模糊糊成一团"。

### 2.3 文本色

| Token | 色值 | 用途 |
|-------|------|------|
| `--text-hi` | `#F2F6FF` | 标题/关键数值 |
| `--text-mid` | `#A8B3CF` | 正文/描述 |
| `--text-dim` | `#5C6784` | 次要说明/禁用态 |
| `--text-on-neon` | `#081018` | 霓虹底按钮上的深色文字 |

对比度要求：正文对底 ≥4.5:1，关键数值 ≥7:1（WCAG AA/AAA）。

### 2.4 稀有度色阶（三选一卡片描边）

`普通 #7A8AA6 → 精良 --neon-cyan → 史诗 --neon-violet → 传说 --neon-amber`
稀有度同时用描边粗细（1/2/2/3px）+ 卡片顶部光带高度区分（双通道）。

### 2.5 伤害飘字分色

| 类型 | 颜色 | 附加 |
|------|------|------|
| 普通命中 | `#F2F6FF` | 字号 14~18px 随伤害对数缩放 |
| 暴击 | `--neon-magenta` | 字号 ×1.5 + 0.1s overshoot 弹跳 |
| 玩家受伤 | `--neon-red` | 屏幕方向内飘 |
| 治疗 | `--neon-lime` | 上飘 + 淡出 |

## 三、字体（Typography)

| 层级 | 字体栈 | 字号/行高 | 用途 |
|------|--------|----------|------|
| Display | `"Orbitron", "Rajdhani", sans-serif`（几何科幻无衬线） | 32~48px / 1.1 | 标题、Boss 名、结算大数字 |
| Number | `"Rajdhani", "Orbitron", monospace 特性 tabular-nums` | 16~28px / 1.2 | 计时器、伤害、货币（等宽数字防跳动） |
| Body（中文） | `"Noto Sans SC", "PingFang SC", sans-serif` | 14~16px / 1.5 | 描述文本、按钮文字 |
| Caption | 同 Body | 12px / 1.4 | 次要说明、tooltip |

**规则**：
- 计时器/金币等高频跳动数字必须 `font-variant-numeric: tabular-nums`，防止宽度抖动。
- 中文标题可用 Body 字体 + `font-weight: 700` + `letter-spacing: 0.08em` 模拟科幻感，不强行用英文 Display 字体渲染中文。
- 全局最小字号 12px；战斗中可读文本（飘字除外）最小 14px。
- 关键标题可加 `text-shadow: 0 0 8px currentColor` 霓虹光晕，正文禁止发光（保可读性）。

## 四、圆润 UI 形状规范（Shape Tokens）

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-s` | `10px` | 小图标底、tag、tooltip |
| `--radius-m` | `16px` | 按钮、列表项、技能槽 |
| `--radius-l` | `24px` | 面板、三选一卡片 |
| `--radius-pill` | `999px` | 血条/经验条/计时器胶囊、主 CTA 按钮 |

- 所有条形控件（HP/EXP/Boss 血条）为**胶囊形**，内部填充同样圆角、留 2px 内边距形成"内管"效果。
- 按钮默认胶囊或 `--radius-m`；按下时 scale 0.96 + 发光增强，禁用直角。
- 例外：Boss 预警横幅与危险区允许斜切角 + 条纹（锐角=危险的形状语义）。

## 五、动画原则（Motion Tokens）

### 5.1 缓动曲线

| Token | 曲线 | 用途 |
|-------|------|------|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场、展开（快进慢停） |
| `--ease-spring` | 弹性 overshoot ~1.06 | 面板弹入、卡片选中、奖励弹出 |
| `--ease-in` | `cubic-bezier(0.7, 0, 0.84, 0)` | 退场、收起 |

### 5.2 时长阶梯

| 场景 | 时长 |
|------|------|
| 战斗微反馈（受击闪白、按钮按下） | 80~120ms |
| 控件过渡（hover、条数值变化） | 150~200ms |
| 面板出入场（三选一、暂停） | 240~300ms |
| 仪式性动效（升级脉冲、Boss 登场横幅） | 400~600ms（唯一允许超 300ms 的类别） |

### 5.3 关键动效清单（与 SOTA F1~F4 对应）

- **升级时间膨胀**：timescale 1→0 用 300ms `--ease-out`，三选一卡片依次错峰 60ms 弹入（`--ease-spring`）；选择后 200ms 缓出恢复。
- **数值条变化**：主条即时变化 + 深色"余影条"以 400ms 延迟追赶（伤害可视化经典手法）。
- **拾取吸入**：宝石 ease-in 加速飞向玩家（初速 0，250ms 内到达），入身时 1 帧白闪。
- **霓虹呼吸**：待机主按钮发光强度 0.4↔0.7 以 2s 正弦呼吸；同屏呼吸元素 ≤2 个。
- **screen shake**：位移型（非旋转），幅度 3 档（2/5/9px），指数衰减 120~250ms；提供开关（可访问性）。
- **减少动效模式**：`prefers-reduced-motion` 下禁用 shake/闪光/呼吸，保留透明度过渡。

## 六、HUD 布局规范

### 6.1 布局总图（横屏 16:9 基准）

```
┌─────────────────────────────────────────────────────────────┐
│ [HP胶囊+等级]      [EXP 全宽细条 · 顶边贴合]      [⏱ 计时] │  ← 顶部状态条（单注视区）
│ [击杀数]                                         [⏸ 暂停]  │
│                                                             │
│                    ═══ Boss 血条（仅Boss战）═══             │
│                                                             │
│                        战斗核心区                            │
│              （中央 60% 无常驻 UI，仅飘字/实体）              │
│                                                             │
│   (移动端: 动态摇杆                                          │
│    触点即原点·半透明)                                        │
│ [武器槽×6 ▢▢▢▢▢▢  配件槽×6 ▢▢▢▢▢▢]                        │  ← 底部构筑栏（图标+等级角标）
└─────────────────────────────────────────────────────────────┘
```

### 6.2 分区规范

**顶部状态条**（`--surface-glass` 玻璃底，高度 ≤64px）
- **EXP 条**：全宽 6px 胶囊贴顶（`--neon-lime` 填充 + 光晕），升级瞬间全条白闪 1 帧 + 扩散脉冲。
- **HP**：左上胶囊条（宽 ~180px），`--neon-cyan` 填充；HP <30% 时切 `--neon-red` + 1.2s 呼吸闪烁 + 屏幕边缘红晕 vignette。等级徽章嵌在 HP 条左端圆形节点内。
- **计时器**：顶部居右（或居中），Display 字体 + tabular-nums；最后 60 秒切 `--neon-amber`。
- **击杀数/金币**：左上 HP 下方小胶囊，图标 + 数字。
- **暂停按钮**：右上角，44×44px 圆形玻璃底。

**底部构筑栏**（高度 ≤56px，玻璃底）
- 武器槽 ×6 + 配件槽 ×6，图标 40×40px、`--radius-m` 圆角底、右下等级角标。
- 新获得项：槽位 `--ease-spring` 弹入 + 稀有度色光环 600ms。
- 满级项：描边切 `--neon-amber` 常亮；可进化项：角标脉冲提示。

**战斗核心区规则**
- 中央 60%（横向 20%~80%、纵向 15%~85%）禁止常驻 UI。
- 屏外目标指示器：贴屏幕边缘的圆角箭头（精英=violet / Boss=red / 宝箱=amber），按距离 0.8~2s 周期脉冲。
- Boss 血条：Boss 战时顶部状态条下方出现全宽胶囊（高 10px），分段刻度标记阶段阈值。

**移动端适配**
- 动态摇杆：左半屏任意触点即摇杆原点，底盘 96px/头 40px，透明度 35%，松手 200ms 淡出。
- 竖屏（9:16）：顶部条压缩为两行，构筑栏收起为可展开胶囊；安全区 `env(safe-area-inset-*)` 全适配。
- 所有可点击目标 ≥44×44px。

### 6.3 三选一面板规范

- 背景：战斗画面压暗 60% + blur 8px；面板无全屏底板，仅 3 张悬浮卡片。
- 卡片：`--surface-1` 底、`--radius-l` 圆角、稀有度描边+顶部光带；宽 ~280px，间距 24px，错峰 60ms 弹入。
- 卡片内容自上而下：图标（64px）→ 名称 + 稀有度 → **before→after 数值对比**（如 `弹道 2 → 3`，after 用 `--neon-lime`）→ 进化路线角标（"⚡ 可与 [护腕] 进化"）。
- 面板底部：当前构筑总览栏（复用底部构筑栏组件）+ 刷新/放弃按钮（次级样式）。
- 选中反馈：卡片 scale 1.04 + 发光爆闪 → 其余两张淡出 → 200ms 关闭恢复时间。
- 键盘支持：1/2/3 数字键直选，方向键+回车可导航。

### 6.4 结算/暂停界面

- 同一套玻璃面板语言；结算数据逐条 80ms 错峰弹入，数字滚动计数（400ms）。
- 主 CTA（再来一局）：`--neon-cyan` 填充胶囊 + 呼吸光；次级按钮为描边幽灵样式。

## 七、实施检查清单（每个 UI PR 必过）

- [ ] 无硬编码色值/圆角/时长——全部引用本文件 token（CSS variables 或常量表）。
- [ ] 危险信息具备 颜色+形状 双通道编码。
- [ ] 正文对比度 ≥4.5:1；发光不施加于正文。
- [ ] 所有动效走缓动 token；战斗反馈 ≤120ms，面板 ≤300ms。
- [ ] 中央 60% 战斗区无新增常驻元素。
- [ ] 375px 宽（iPhone SE）与 2560px 宽下布局无溢出/重叠。
- [ ] `prefers-reduced-motion` 与"关闭震动/闪光"设置生效。
