# 蛋壳特工：元素觉醒 — 游戏设计文档（GDD）

> Round 1 / fable-1 产出。数值以本文 §16 为基线；系统接口以 ARCHITECTURE.md 为准。

---

## 1. 定位与体验支柱

- 一句话：**「割草爽感 × 元素化学 × 弹幕舞蹈」**的 15 分钟 Roguelike 生存射击。
- 对标并超越蛋壳特工队（Survivor.io）的四个抓手：
  1. 竞品«站桩割草»→ 我们用**连击窗口 + Boss telegraph + 场地事件**逼迫走位，操作有深度；
  2. 竞品固定进化表 → 我们的**元素反应 + 自由融合**让每局 build 涌现；
  3. 竞品静态地图 → **活的竞技场**（障碍战术 + 动态事件）；
  4. 竞品挂件宠物 → **元素协同宠物**参与 build 决策。
- 体验支柱：每 30 秒一个决策点；每次命中都有反馈（音效/粒子/数字/微震）；死亡要能自我归因。

## 2. 核心循环

```
移动躲避 → 自动射击割草 → 拾取 XP → 升级三选一 → 元素成型 → 融合质变
   ↑                                                            ↓
 死亡/通关 ← 15:00 终盘狂潮 ← Boss③ ← 10:00 Boss② ← 5:00 Boss①
```

单局 15 分钟通关制（存活到 15:00 击杀最终 Boss = 胜利）。局外元进度轻量（§15）。

## 5. 元素与反应

见 ARCHITECTURE §7.1 反应表。设计意图：**火=爆发、冰=控制、电=扩散、毒=持续、虚空=聚怪**；任意双元素都有正反馈，避免«唯一正解»。UI 上敌人头顶显示元素层数小图标（≤2 种）。

## 9. 连击与 Fever（数值）

见 ARCHITECTURE §7.3。补充手感设计：连击计数器在玩家头顶右上，tier 越高字体越大、颜色 白→黄→橙→红→彩虹；tier up 时全屏轻震 + 音高上行音效；Fever 进入时 BGM 加鼓点层。

## 10. 宠物（5 只，见 ARCHITECTURE §7.5）

获取：升级卡池的 rare 卡；共鸣（宠物元素=任一武器元素）时宠物变大 20% 并加粒子拖尾。宠物主动技 CD 显示为宠物脚下小环。

## 11. 地形与场地事件

见 ARCHITECTURE §7.4。地图 3200×3200，出生点中心；障碍密度由 `data/terrain.js` 的泊松盘采样参数控制（间距 ≥ 260px 保证走位空间）；地图边缘为电子围栏（触碰弹回 + 5 伤害）。

## 12. 升级三选一（UX）

- 升级瞬间：时间冻结、背景暗角模糊、3 张卡从下方 120ms 依次弹入（CSS）。
- 卡面：图标（程序化 48px）、名称、稀有度描边（灰/蓝/紫/金=融合）、一行效果、当前→下一级数值 diff。
- 顶部小字提示融合进度：「蒸汽机炮：还差 冰晶回旋镖 Lv5」。
- 底部按钮：重掷(×2) / 放逐(×1) / 跳过(+25 金币)。

## 13. UI / 视觉风格指南

- **基调**：深色战场 + 高饱和霓虹发光元素 =「可爱角色 × 电竞反馈」。卡通描边角色，命中特效走 additive glow。
- 配色 token（CSS 变量 + JS 常量同源 `data/meta.js`）：
  - 背景 `#12141c`，地面纹理 `#1a1e2a`，UI 面板 `#1f2433ee`
  - 元素色：火 `#ff6b35` 冰 `#4dd8ff` 电 `#ffe14d` 毒 `#8bde3f` 虚空 `#b96bff`
  - HP `#ff4d6b`，XP `#57ffa0`，金币 `#ffd166`，暴击数字 `#ffef5c`
- 字体：系统栈 `'Segoe UI', 'PingFang SC', sans-serif`；数字用等宽变体防抖动。
- HUD 布局：顶部通栏 XP 条；左上 HP/护盾+计时器；右上 击杀/金币；左下 武器/被动 2×6 图标格；右下 宠物头像+技能环；Boss 战顶部第二条 Boss 血条；连击计数跟随玩家。
- Juice 清单（验收必查）：命中闪白、伤害数字、死亡爆裂粒子、屏震(分级)、hitStop、拾取吸附曲线、升级全屏光环、融合金色冲击波、低血红晕脉冲、Fever 边缘火焰。
- 移动端：≥ 768px 宽横屏布局；虚拟摇杆左半屏任意落点；HUD 元素放大 1.25×。

## 14. 音频方向

芯片风(chiptune-lite)：BGM 小调五声琶音 100 BPM，Boss 战 140 BPM 加噪声军鼓；SFX 全合成（见 ARCHITECTURE §6.7）；连击 tier 音效音高沿大调音阶上行（成长感）；全局限幅防爆音。

## 15. 元进度（轻量）

金币局内拾取带出 → 主菜单「蛋壳研究所」永久升级（每项 5 级）：
基础伤害 / 最大 HP / 移速 / 磁吸 / 初始重掷+1 / **备用蛋壳**（每局一次原地复活 50% HP，替代竞品的广告复活）。
解锁线：角色 2–4 号分别由「首次击杀 Boss①/②/③」解锁；宠物由累计元素反应次数解锁。
